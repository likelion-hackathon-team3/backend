# AiServer 기획 문서

## 1. 프로젝트 개요
* **프로젝트명**: AiServer
* **시스템 역할**: 메인 백엔드 서버와 독립적으로 분리된 AI 전용 마이크로서비스.
* **통신 방식**: 메인 백엔드 서버와 REST API를 통해 통신하여 AI 처리 결과를 반환한다.

## 2. 핵심 기능 요구사항
### 2.1 근무표 사진 인식 (OCR)
* **설명**: 사용자가 업로드한 근무표 사진 이미지를 분석하여 근무 일정 텍스트 데이터를 추출한다.
* **적용 기술**: OpenAI Vision API (Spring AI 활용)
* **입력**: 근무표 이미지 파일 또는 이미지 URL (메인 백엔드로부터 API를 통해 전달받음)
* **출력**: 인식된 근무표 텍스트를 구조화된 데이터(JSON 형태)로 반환

## 3. 아키텍처 및 통신 플로우
1. **클라이언트** -> (사진 업로드 요청) -> **메인 백엔드 서버**
2. **메인 백엔드 서버** -> (API 호출 및 이미지 데이터 전달) -> **AiServer (본 프로젝트)**
3. **AiServer** -> (OpenAI Vision API 호출하여 이미지 분석 및 텍스트 추출)
4. **AiServer** -> (결과 JSON 응답) -> **메인 백엔드 서버**
5. **메인 백엔드 서버** -> (DB 저장 및 최종 응답) -> **클라이언트**

## 4. 개발 환경 및 필수 설정
* Spring Boot 기반 서버 구축
* OpenAI API Key 설정 필수 (환경변수 `OPENAI_API_KEY` 적용)
