# 02 — 프롬프트 내 수면 독점 구간 및 식사 선행 원칙 불변식 강화

**What to build:**
프롬프트 템플릿(`timeline_today.st`, `timeline_future.st`)에 수면 독점 구간(수면/쪽잠 시간 중간에 다른 활동 절대 배치 금지) 및 식사 선행 원칙(수면 1시간 전 식사 완료)을 명시하여, AI가 쪽잠을 자는 도중에 식사를 배치하는 비현실적인 일정을 생성하지 않도록 규칙을 강화합니다.

**Blocked by:** 01 — 타임라인 시간순 자동 정렬(Chronological Auto-Sorting) 안전망 구축

**Status:** resolved

- [x] 수면(SLEEP) 및 쪽잠(NAP) 진행 시간대에는 다른 어떠한 활동도 중복 배치되지 않는다.
- [x] 식사(MEAL)는 수면/쪽잠 시작 최소 1시간 전에 완료되거나, 기상 후 적절한 여유를 두고 배치된다.
- [x] OFF → NIGHT 등 야간 출근 시나리오에서 식사 후 쪽잠 → 기상 → 출근 준비로 이어지는 자연스러운 흐름이 생성된다.
