# 01 — 타임라인 시간순 자동 정렬(Chronological Auto-Sorting) 안전망 구축

**What to build:**
AI 모델이 비결정적으로 항목의 순서를 뒤섞어 반환하더라도, 서비스 계층에서 호출 시점 기준의 시간 흐름(자정 넘김 안전 처리)에 맞추어 `timelineItems` 리스트를 시간순 오름차순으로 100% 보장 정렬하여 클라이언트에 전달하는 안전망을 구축합니다.

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] AI 응답의 `timelineItems` 리스트가 순서에 상관없이 항상 시간 흐름순("HH:mm" 오름차순)으로 자동 정렬된다.
- [x] 자정을 넘어가는 일정(예: 18:00 시작 ~ 익일 07:00 근무)에서도 시간이 왜곡되지 않고 정상 순서로 정렬된다.
- [x] 뒤섞인 시간(예: 20:30, 22:00, 22:30, 21:00)이 입력되어도 20:30 → 21:00 → 22:00 → 22:30으로 올바르게 정렬되는 단위 테스트를 통과한다.
